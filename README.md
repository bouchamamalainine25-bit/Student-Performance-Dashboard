# Student Performance & Academic Success (ERL Project) 🎓📊

A comprehensive End-to-End Data Engineering & Business Intelligence project designed to analyze student lifestyle factors and their direct impact on academic performance.

## 📌 Project Overview
This project was developed as part of an **ERL (Étude de Réalisation)** to build a complete pipeline: extracting and transforming raw data, storing it, and visualizing actionable insights through an interactive Executive Dashboard.

## ⚙️ Architecture & Tech Stack (ETL Pipeline)
* **Data Extraction & Transformation (ETL):** Talend Open Studio (Cleaning, filtering, and preparing the raw student dataset).
* **Database:** MySQL / Relational Database (Hosting the structured data).
* **Visualization & BI:** Power BI (Building the interactive dashboard & KPIs).
* **Version Control:** Git & GitHub.

## 🚀 Key Pipeline Steps
1. **Data Preparation:** Raw data imported and cleaned using Talend pipelines.
2. **Data Modeling:** Structuring relationships and preparing calculated measures.
3. **Dashboard Development:** Designing a multi-metric, executive-level Power BI report focusing on attendance, study hours, peer influence, and school types.

## 💡 Key Business Insights
* **Attendance Correlation:** Clear positive linear trend between student attendance rates and exam scores.
* **Study Habits:** Normal distribution observed in study hours, highlighting optimal ranges for student success.
* **Socio-Economic & Environmental Impact:** Insights on how parental education, internet access, and peer influence shift academic results.
